# NXVinyl

NXVinyl steps forth as a new iteration of background music playing on the Switch. Inspired by TriPlayer, NXVinyl aims to provide a lightweight audio player with easy to access controls via an overlay. With the accompanying NRO you get a full media player as well as scanning your music folder and setting equalizer presets.

I started this project to recover from the disastrous firmware update (21.0.0) that broke so much homebrew.
## Special Thanks

[@tallbl0nde] - For the TriPlayer codebase

## Features

- Background audio playback while games/apps are running
- Supports mp3, WAV, FLAC
- Playlist creation!
- Metadata scraping
- Low-overhead
- 12-band equalizer (with custom presets)
- Add and remove songs to your queue

## Requirements
- Nintendo Switch running Atmosphere
- Tesla-Menu

## Usage

1. Copy the contents of NXVinyl to the root of your SD card
2. Launch via the Ultrahand
3. Scan your library
4. Enjoy the music!
